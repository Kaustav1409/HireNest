# HireNest

HireNest is an intelligent recruitment platform that connects job seekers and recruiters using skill-based matching, quiz validation, and personalized learning suggestions to improve hiring accuracy and career growth.

## Run locally

```powershell
powershell -ExecutionPolicy Bypass -File compile-enhancements.ps1
.\start-hirenest.bat
```

Open http://localhost:9090/

See [DEPLOY.md](DEPLOY.md) for GitHub push and cloud deploy steps.
